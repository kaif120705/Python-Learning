## Programs Completed

- Decimal to Octal Conversion
- Decimal to Hexadecimal Conversion
- Binary to Decimal Conversion

## Key Concepts Learned
- Computers use binary (0 and 1).
- Python provides built-in functions for number system conversion.
- bin(), oct(), and hex() return string values with prefixes (0b, 0o, 0x).
- int(value, base) converts a number from another base to decimal.
